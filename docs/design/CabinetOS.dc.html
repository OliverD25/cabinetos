CabinetOS

A developer-first file manager for Windows 11. Dual panes, workspaces, an integrated terminal and a WebAssembly plugin system, wrapped in Fluent.

build passing v0.9.2 MIT

Getting started

winget install CabinetOS.CabinetOS
cargo run --release -- --workspace .

Concepts

  • Workspaces group folders, pane state and terminal sessions.
  • Panes host a folder list or any editor a plugin provides.
  • Commands are everything. Every action has an id and a keybinding.

Plugins

Plugins are sandboxed WebAssembly modules. They declare capabilities up front and are reviewed at install time. See docs/plugins.md.
